# Screens: the chosen design, as screenshots

From the throwaway prototype of fund-gate (`prototype/screens`, issue #17). The decision is in [screens.md](../../playbook/screens.md): the dealer screen is variant C (reply-first answer sheet), the validation screen is variant A (document beside the rules) with the contradiction banner. Reproduce the look and layout in Angular; do not copy the prototype's code.
